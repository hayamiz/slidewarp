# samples

slidewarp の検出頑健性を検証するための**公開用サンプル**です。元写真（`input-samples/`、非追跡）から
難ケース代表を厳選し、プライバシー保護（顔のモザイク）・著作権配慮（スライド内部のぼかし）・
EXIF 除去を施しています。

## 匿名化の方針

- **スライド内部**: 軽いガウシアンぼかし。スライドの**四辺エッジは無処理**で残すため、slidewarp の
  検出結果は元写真とほぼ一致します（回帰テスト性を維持）。モザイク（ブロック化）は内部に軸平行の
  境界エッジを作り Hough 検出を誤らせるため、ぼかしを採用しています。
- **顔／人物**: モザイク（人物セグメンテーションの上部バンドを pixelate）。
- **EXIF/メタデータ**: 全除去。

生成ツール: `python/scripts/anonymize_samples.py`（設定 `python/samples.toml`）。
設計・計画は `docs/superpowers/specs/2026-08-07-anonymize-samples-design.md` /
`docs/superpowers/plans/2026-08-07-anonymize-samples.md`。

## 公開サンプルに含めていない難ケース

以下は「匿名化すると検出結果が元と大きく変わる」ため、回帰サンプルとして公開していません
（元写真は各自の `input-samples/` で検証してください）。

- **2026-06-24 19.47.29**（登壇者が前に立つ）— 登壇者の顔を覆うと、スライドを遮る人物領域が
  変わり検出枠が約 70px ずれる。人物遮蔽ケース固有の限界。
- **2026-06-24 19.55.25**（超斜め・暗所）— 既知の最難ケース。内部をどう匿名化しても検出が
  大きくずれる（上辺が低コントラストで元から検出が不安定）。
